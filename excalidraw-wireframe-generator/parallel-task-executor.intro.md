# Parallel Task Executor 技能支持的指令模式

## 核心触发指令模式

### 1. 显式请求并行执行
- **指令示例**: 
  - "请并行执行这些任务"
  - "同时处理多个任务"
  - "启动并行执行"
  - "加速执行这些任务"

### 2. 包含并行相关关键词
- **触发关键词**: 
  - "并行"、"并发"、"同时"、"speed up"、"concurrent"、"simultaneous"
- **指令示例**: 
  - "我需要并行分析前端和后端代码"
  - "请同时测试多个API端点"
  - "能否并发处理这些任务以加快速度"

### 3. 多任务请求
- **指令模式**: 提出多个独立任务
- **示例**: 
  - "分析前端架构、后端API设计和数据库模式"
  - "实现用户认证、权限管理和个人资料功能"
  - "测试登录、注册和密码重置功能"

### 4. 大型任务分解
- **指令模式**: 提出一个大型任务，隐含可分解为多个子任务
- **示例**: 
  - "分析整个应用架构"
  - "构建完整的用户管理系统"
  - "测试整个API接口集"

## 可用的代理类型指令

当使用该技能时，系统会根据任务类型自动选择合适的代理：

| 代理类型 | 适用任务 | 指令示例 |
|---------|---------|---------|
| `search` | 代码库探索和研究 | "搜索认证实现" |
| `ui-designer` | UI/UX设计任务 | "设计用户界面" |
| `frontend-architect` | 前端实现 | "构建前端组件" |
| `backend-architect` | 后端开发 | "实现后端API" |
| `api-test-pro` | API测试 | "测试API接口" |
| `ai-integration-engineer` | AI/ML功能 | "集成AI模型" |
| `performance-expert` | 性能优化 | "优化系统性能" |
| `compliance-checker` | 法律合规审查 | "检查合规性" |
| `whitebox-tester` | 单元测试 | "编写单元测试" |
| `ui-architect` | 生产级UI开发 | "构建完整界面" |

## 系统响应模式

当触发该技能时，系统会：

1. **识别可并行执行的任务**
2. **选择合适的代理类型**
3. **批量启动多个Task工具**
4. **收集并整合所有结果**
5. **返回综合结果给用户**

## 实际应用示例

### 场景1：多维度分析
**用户指令**: "分析前端架构、后端API和数据库设计"

**系统响应**: 
- 启动并行任务：
  - Task 1 (search): 分析前端架构和组件结构
  - Task 2 (search): 分析后端架构和API设计
  - Task 3 (search): 分析数据库架构和数据模型
- 收集所有结果并整合返回

### 场景2：多功能实现
**用户指令**: "实现用户认证、权限管理和个人资料功能"

**系统响应**: 
- 启动并行任务：
  - Task 1 (backend-architect): 设计实现认证系统
  - Task 2 (backend-architect): 设计实现授权系统
  - Task 3 (frontend-architect): 构建认证UI组件
  - Task 4 (frontend-architect): 构建个人资料管理界面
- 收集所有结果并整合返回

该技能会自动识别合适的指令模式，并以最佳方式并行执行任务，显著减少总体完成时间。
