# excalidraw-wireframe-generator 技能说明

## 核心功能

excalidraw-wireframe-generator 是一个用于生成可编辑 Excalidraw 线框图和图表的技能，支持两种输入模式：

- **描述生成模式**：根据文字描述创建线框图
- **网页转换模式**：将现有网页（URL/截图）转换为 Excalidraw 线框图

它利用 UI/UX 设计能力，专注于创建清晰、手绘风格的 Web 界面可视化文件，支持多种自动触发机制，确保线框图与设计需求保持同步。

## 主要用途

- 为 Web 应用或移动应用创建线框图
- 可视化 Web 界面布局和组件
- 创建手绘风格的 Web 设计图表
- 根据 Web 设计需求生成可编辑的 Excalidraw 文件
- 将现有网页（URL/截图/HTML）转换为 Excalidraw 线框图
- 前端页面文件（HTML/CSS）修改时自动更新线框图
- 用户指定包含视觉交互内容的需求文档时自动生成线框图

## 两种输入模式

### 模式 A：描述生成模式

**触发关键词**：帮我画、设计一个、创建线框图、wireframe、布局

**输入**：文字描述的 Web 界面需求

**示例**：帮我画一个登录页面，包含用户名、密码输入框和登录按钮

**流程**：

1. 解析用户描述
2. 识别组件和布局
3. 生成 Excalidraw 元素
4. 应用手绘风格
5. 验证布局和绑定
6. 导出 .excalidraw 文件

### 模式 B：网页转换模式

**触发关键词**：把这个网页、转换为线框图、转成 excalidraw、还原设计

**输入**：网页 URL、截图或 HTML/CSS 文件

**示例**：

- 把 https://example.com 转成 excalidraw 线框图
- 根据这个截图生成线框图

**流程**：

1. 捕获网页（URL/截图）
2. 分析布局结构
3. 提取组件和关系
4. 高保真生成 Excalidraw
5. 应用手绘风格（不改变布局）
6. 验证绑定和间距
7. 导出 .excalidraw 文件

**特殊处理**：

- 保持原始布局比例
- 维持组件关系
- 识别交互元素（按钮、输入框、链接）
- 突出用户流程连接

## 技术特性

- 严格采用手绘风格，保持 Excalidraw 特色
- 始终使用 `version: 2` 确保最大兼容性
- 支持响应式设计，展示多设备布局
- 自动处理 UI/UX 设计需求
- 可生成独立的子页面和窗口线框
- 支持组件和控件的 CSS 属性表示
- 可添加动画交互描述
- 生成的文件完全可编辑
- 支持组件复用和自定义组件创建
- 清晰的图层组织和命名规范
- 高质量的文字和排版处理
- 符合无障碍设计标准的配色方案
- 有效利用无限画布空间，避免元素重叠
- 合理组织画布上的元素，保持清晰的逻辑结构
- 为复杂设计提供清晰的画布导航
- **智能箭头连接**：箭头与图形自动连接，移动图形时箭头随之移动
- **箭头绑定验证**：所有箭头必须绑定到有效目标，无游离箭头
- 一致的箭头样式和清晰的方向指示
- 避免不必要的箭头重叠
- **默认条纹图案填充**：使用条纹作为默认的图案填充效果，确保线框图的一致性和可读性
- **布局助手**：程序化定位（below/right_of/auto_labeled_rect），减少手动计算
- **布局验证**：自动检测重叠、箭头绑定、间距一致性

## 核心设计原则

- 总分设计方法：先提供整体指导，再详细说明各方面规范
- 统一绘制语言：保持一致的风格、版本和标注方式
- 清晰柔和的配色：遵循 WCAG 对比度指南，减少眼部疲劳
- 精确的文字间距：确保可读性和美观性
- 忠实还原设计：准确呈现原始布局、样式和组件

## 自动触发机制

- **前端文件变化**：监控 HTML/CSS 文件，自动响应创建、修改或删除操作
- **需求文档指定**：当用户明确指定包含视觉交互内容的需求文档时
- **定时更新**：可配置为特定间隔运行，确保线框与设计保持同步
- **批量处理**：短时间内修改多个文件时，汇总变化并触发单次更新

## 输出格式与位置

- 文件类型：Excalidraw 可视化文件 (.excalidraw)
- 默认输出路径：项目根目录 /wireframes
- 始终使用 `version: 2`，兼容最新版本的 Excalidraw 编辑器
- 生成的文件包含清晰的注释和样式标注

## 使用建议

1. 确定使用哪种模式（描述生成 或 网页转换）
2. 提供清晰的 Web 设计需求或描述 / 网页 URL 或截图
3. 指定需要生成的页面和组件类型
4. 说明是否需要添加动画交互描述
5. 配置前端目录监控以启用自动更新
6. 任务完成后检查生成的线框图，并提供反馈
7. 可直接在 Excalidraw 编辑器中修改和优化生成的文件
8. 利用版本控制功能跟踪线框迭代

## 最佳实践

- 使用清晰简洁的标注：保持注释与元素靠近
