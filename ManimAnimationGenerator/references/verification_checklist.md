# 验证清单模板

AI 在输出最终代码前必须逐项自检：

## 内容完整性
- [ ] 知识图谱中的每个原子至少对应一个动画步骤。
- [ ] 每个反直觉点都有专门的证伪步骤。
- [ ] 至少包含一个生活/工程应用案例（若用户要求深度）。
- [ ] 教学路径覆盖七个阶段（激活、直观、定义、运算、反直觉、应用、总结），路径文案不展示在动画中。
- [ ] 每个知识原子已标注教材或知识库来源（若为 AI 生成草案则标注待核对）。
- [ ] 若用户提供了教材名称，检查代码注释中是否引用了对应章节。
- [ ] 讲解深度每个新概念满足：定义明确 + 直观解释 + 至少一个例子（必须与用户确认） + 连接前置知识 + 反直觉澄清（如适用）
- [ ] 每个原子元素数量 <= 8
- [ ] 每个原子预估高度 <= 5.5 单位（垂直排列时）
- [ ] 每个原子预估宽度 <= 12 单位（水平排列时）
- [ ] 重要公式已独立成原子
- [ ] 已调用 split_atom.py 检查并拆分超长原子
- [ ] **【数理正确性】所有坐标由数学公式推导（中点、交点、切点等），无硬编码**
- [ ] **【数理正确性】几何关系已验证（距离、角度、平行、垂直、相切）**
- [ ] **【数理正确性】物理定律已体现（如适用：牛顿定律、动量守恒、基尔霍夫定律等）**

## 布局底座引用
- [ ] 场景类继承自 `LayoutScene`（来自 `scripts/layout_base.py` ）
- [ ] 使用了 `safe_place()` 或 `arrange_centered()` 等布局方法

## MathTex vs Tex 规范
- [ ] 纯数学公式使用 MathTex，含中文的混合内容使用 Tex
- [ ] MathTex 中无中文字符
- [ ] Tex 中的公式已用 $...$ 包裹

## 布局与视觉
- [ ] 所有教学内容最小 Y >= -2.8，字幕区无其他对象。
- [ ] 元素间距 >= 0.6 或 0.3，无不重叠冲突。
- [ ] 坐标无硬编码，均使用相对定位或数学推导。
- [ ] 若使用坐标系，轴线范围超出图形内容边界。
- [ ] **【坐标参考系】涉及坐标计算的场景已添加 Axes 或 NumberPlane**
- [ ] **【坐标参考系】使用 axes.c2p() 转换坐标，无硬编码 [x, y, z]**
- [ ] X 轴和 Y 轴必须包含正负方向，有轴名标识
- [ ] 主内容已主动定位到顶部居中（Y = 2.0），而非依赖 safe_place 随机放置
- [ ] 使用了 align_to(ORIGIN, UP) + shift(UP * 2.0) 实现顶部对齐
- [ ] 视频结尾有知识网络图（展示当前概念与前后关联）。
- [ ] 标题区位于 Y = 3.5（如无标题则跳过）
- [ ] 副标题区位于 Y = 2.8 或紧贴标题下方
- [ ] 主内容区从顶部开始排列（首个元素 Y = 2.0 到 2.5）
- [ ] 无主内容时，标题/副标题整体垂直居中
- [ ] 分栏时各栏内容从顶部开始排列（首个元素 Y = 2.0）
- [ ] 分栏时各栏顶部对齐
- [ ] 分栏组合整体水平居中
- [ ] 分栏模式字体大小符合规范（单栏34、两栏32/34/28、三栏28/32/26）
- [ ] 单个原子内的 content 元素使用垂直排列（默认）或自动切换为水平/两栏
- [ ] 垂直排列时整体顶部居中（Y = 2.0）
- [ ] 水平排列时整体垂直居中（Y = 0）
- [ ] 内容未超出屏幕边界（水平 <= 13 单位，垂直 <= 6.5 单位）

### 布局完整性验证场景（强制执行）

代码完成后，必须生成一个包含以下所有元素的单一验证场景，确保布局规范被正确实现：

#### 1. 单栏布局验证
- 标题区：顶部居中 Y=3.5
- 副标题区：Y=2.8
- 主内容区：垂直排列 5 行独立公式，顶部居中 Y=2.0，居中左对齐
- 图形区：无
- 字幕区：30 字字幕，自动滚动（不显示滚动条）

#### 2. 两栏布局验证
- 标题区：顶部居中 Y=3.5
- 副标题区：Y=2.8
- 主内容区：垂直排列 5 行独立公式，左栏
- 图形区：坐标系 + 正弦函数图 y = sin(x)，右栏
- 字幕区：30 字字幕，自动滚动

#### 3. 三栏布局验证
- 标题区：顶部居中 Y=3.5
- 副标题区：Y=2.8
- 左栏：概念定义 + 公式定理（文字描述 + 核心公式）
- 中栏：5 行独立公式（极限、微积分等，与两栏不重复）
- 右栏：坐标系 + 立体几何（如立方体或球体）
- 字幕区：50 字字幕，自动滚动

#### 验收标准
- [ ] 各区域无重叠、无溢出
- [ ] 坐标系轴线超出图形内容边界
- [ ] 字幕区 Y ∈ [-3.85, -2.8]，内容不超出
- [ ] 5 行公式垂直间距 ≥ 0.6，无重叠
- [ ] 三栏布局各栏顶部对齐
- [ ] 立体几何使用 ThreeDScene 或 3D 投影

## 教学内容文件
- [ ] 已生成独立的 JSON 教学内容文件，且所有原子均被代码实现覆盖
- [ ] JSON 文件包含主题、版本、来源、前置知识、教学原子序列
- [ ] JSON Schema 校验已通过（运行 `scripts/validate_course_contents.py --input courses/xxx.json`，无错误输出）

## 字幕
- [ ] 基于教学内容文件确定，每次字幕输出不允许超过 2 行。
- [ ] 字幕使用 split_utterance 拆分长句。
- [ ] 动画与语音时长匹配（误差小于 0.2 秒）。

## TTS 语音（如适用）
- [ ] 已根据用户选择配置正确的 TTS 服务（云端TTS / EdgeTTS）
- [ ] 依赖已完整安装（PortAudio、SoX、gettext）
- [ ] 渲染命令包含 --disable_caching
- [ ] 若使用 EdgeTTS，已告知用户发音限制

## 动画效果
- [ ] 文字使用 AddTextLetterByLetter 实现打字机效果
- [ ] 公式使用 Write 逐步绘制
- [ ] 元素间有适当延迟（0.1 到 0.3 秒）

## 符号转义（语音生成）
- [ ] Unicode 数学符号已转义（如不等于、小于等于、角、垂直于等）
- [ ] LaTeX 数学符号已转义（如 neq、leq、times、frac 等）
- [ ] 希腊字母已转义（如 alpha、beta、gamma 等）
- [ ] 物理符号和单位已转义（如矢量箭头、牛顿、焦耳等）

## 图形内容
- [ ] 所有几何图形顶点由数学公式推导，无硬编码
- [ ] 立体几何使用了 ThreeDScene 和相机控制
- [ ] 物理物体使用了正确的颜色和标注（重力绿、弹力蓝、摩擦红）
- [ ] 线性代数图形展示了基向量或坐标变换
- [ ] 等腰/等边标记已添加（斜线、竖线）
- [ ] 每个教学阶段配对的图形类型与阶段目的一致
- [ ] 图形区位于右侧，与主内容区顶部对齐
- [ ] 图形动画与 visual_action 配合正确

## 指数与对数（如适用）
- [ ] 是否展示了乘法变加法/幂变乘法的降维对比动画？
- [ ] 是否包含对数定义式（指数式与对数式对应关系）？
- [ ] 是否解释了 log_a 1 = 0 和 log_a a = 1 的反直觉点？

## 概率统计（如适用）
- [ ] 古典概型是否清晰展示了样本空间？
- [ ] 排列组合是否有树状图/分步动画？
- [ ] 条件概率是否使用维恩图缩小样本空间？
- [ ] 期望是否解释了长期平均与最可能值的区别？
- [ ] 大数定律是否有频率收敛的动态演示？
- [ ] 正态分布是否标注了 68-95-99.7 法则？

## 物理学科（如适用）
- [ ] 力矢量颜色正确，标签规范。
- [ ] 力矢量从正确的作用点出发
- [ ] 运动轨迹使用虚线 + 箭头
- [ ] 电场线/磁感线方向正确，电路图元件标准。
- [ ] 物理定律被验证或解释。

## 电路与磁场（如适用）
- [ ] 电路图元件符号标准化（电池、电阻、开关、电流/电压表）
- [ ] 电流方向标注明确（正电荷方向）
- [ ] 垂直纸面方向已用 ⊙ 或 ⊗ 标注
- [ ] 左手/右手定则动画分步演示，并辅助手型图标
- [ ] 楞次定律包含增反减同提示和磁通量变化动画
- [ ] 混联电路局部断路不影响全局通路的反直觉点已澄清

## 分场与全场（如适用）
- [ ] 若总原子数 > 30，已拆分为多个场景，每个场景独立可渲染。
- [ ] 提供了合并脚本或命令行指导，可生成全场视频。
- [ ] 每个拆分后的场景已独立通过本清单的所有其他章节检查（布局、公式、语音等）。
- [ ] 拆分后的场景之间无内容跳跃或逻辑断层。

## 代码质量
- [ ] 包含所有必需的 import（manim, manim_voiceover）。
- [ ] 类名 PascalCase，文件名合理。
- [ ] 头部包含依赖安装注释和配置字典。
- [ ] 渲染命令包含 --disable_caching。

## 错误处理与回退
- [ ] 坐标计算不会产生除零或无穷大（已预检查）。
